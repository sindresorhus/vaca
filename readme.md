# vaca

> Get a random ASCII cow 🐮

<img src="screenshot.png" width="668">

## Install

```sh
npm install vaca
```

## Usage

```js
import vaca from 'vaca';

console.log(vaca());
//=> '...'
```

### CLI

```sh
npm install --global vaca
```

```sh
vaca
```
